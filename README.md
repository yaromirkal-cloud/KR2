# Курсовая работа: Разработка алгоритмов обработки естественных языков

**Автор:** Студент
**Специальность:** Информатика и вычислительная техника
**Уровень образования:** Бакалавриат

## Описание проекта

Данный проект содержит полную курсовую работу на тему «Разработка алгоритмов обработки естественных языков» с практической реализацией основных алгоритмов НЛП на Python.

## Структура проекта

```
KR2/
├── README.md                          # Этот файл
├── coursework.md                      # Полный текст курсовой работы
├── examples/
│   ├── 01_text_preprocessing.py       # Предварительная обработка текста
│   ├── 02_tokenization.py             # Токенизация
│   ├── 03_lemmatization.py            # Лемматизация и стемминг
│   ├── 04_sentiment_analysis.py       # Анализ тональности
│   ├── 05_ner.py                      # Извлечение именованных сущностей
│   ├── 06_text_classification.py      # Классификация текстов
│   ├── 07_comparison.py               # Сравнение алгоритмов
│   └── requirements.txt                # Зависимости
├── data/
│   └── sample_texts.txt               # Примеры текстов для обработки
└── diagrams/
    └── algorithms_overview.txt        # Описание диаграмм
```

## Как использовать

### Установка зависимостей

```bash
cd examples
pip install -r requirements.txt
```

### Запуск примеров

```bash
python 01_text_preprocessing.py
python 02_tokenization.py
python 03_lemmatization.py
python 04_sentiment_analysis.py
python 05_ner.py
python 06_text_classification.py
python 07_comparison.py
```

## Содержание курсовой работы

1. **Введение** - актуальность НЛП, цели и задачи
2. **Основные понятия НЛП** - определения, история развития
3. **Предварительная обработка текста** - очистка, нормализация
4. **Токенизация** - разделение текста на токены
5. **Лемматизация и стемминг** - приведение к начальной форме
6. **Анализ тональности** - определение эмоционального окраса
7. **Извлечение именованных сущностей** - выделение сущностей
8. **Классификация текстов** - распределение по категориям
9. **Сравнительный анализ** - производительность и точность
10. **Практическая реализация** - интегрированная система
11. **Заключение** - выводы и перспективы
12. **Список использованных источников**
